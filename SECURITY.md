# Security Policy

## Supported Versions

The latest version of Onyx is actively supported with security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x | :x:                  |
| < 4.0.x | :heavy_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**Do not open a public GitHub issue**, as this may expose the vulnerability before it can be fixed.

Instead, please contact the project maintainer through one of the following methods:

* GitHub Security Advisories (preferred, if enabled)
* GitHub Discussions or another private contact method provided by the project

When submitting a report, please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* Any proof of concept or screenshots (if applicable)
* The affected version of the software

### What to Expect

* You will receive an acknowledgment within **72 hours**.
* Reports will be investigated as quickly as possible.
* If the vulnerability is confirmed, a fix will be be developed and released in a future update.
* Credit may be given to the reporter unless they prefer to remain anonymous.
* If the report is determined not to be a security vulnerability, an explanation will be provided whenever possible.

Thank you for helping keep Onyx secure for everyone.
